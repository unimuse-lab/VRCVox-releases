# VRCVox

VRChat のマイクを自動でミュート・アンミュートする Windows 用常駐アプリです。
このリポジトリはインストーラーとアップデートの配布専用です（ソースコードは含みません）。

## ダウンロード

[最新版のインストーラー（VRCVox-win-Setup.exe）](https://github.com/unimuse-lab/VRCVox-releases/releases/latest/download/VRCVox-win-Setup.exe)

過去のバージョンや変更内容は [Releases](https://github.com/unimuse-lab/VRCVox-releases/releases) を参照してください。
インストール後は、アプリが自動で新しいバージョンを確認します。

## 動作環境

- Windows 10 / 11（64bit）
- VRChat（OSC を有効にしてください）
- Discord 連携を使う場合は Discord デスクトップアプリ
